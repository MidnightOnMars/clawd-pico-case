# Atomic Wedgie base v2 (RP2040-Plus with a battery)

Old test. Print from `stl/atomic-wedgie/`.

**`reset-button.stl` is not a front button.** It is the small RESET plunger that sits in this base only. If someone asks for "buttons", they mean the four front caps, `stl/current/button.stl`. Print the RESET button only for an Atomic Wedgie, one per base.

Red PETG.
- `base-floor-down.stl`: battery plug slot to the top (no catch on that end), BOOT pin hole, RESET hole.
- `reset-button.stl`: RESET button v3 (black), flange down, no brim or raft. Drop it in from inside before the board.

Lid, joystick and buttons from `stl/current/`.
